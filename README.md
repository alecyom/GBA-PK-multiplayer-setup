# GBA-PK-multiplayer

## Downloads

These are all the files you need to download for pokemon multiplayer

- Download the latest mGBA release for your device: [https://mgba.io/downloads.html]
- Download the .gba file of the game you want to play from the repo (multiplayer mod is only compatible with gen 3 games)
- Download GBA-PK_Multiplayer.lua from the repo

## Setup

Once all files are installed:

- Open the mGBA app and from options, go to File > Load ROM and select the .gba game file that you downloaded
- When in-game, go to options again and select Tools > Scripting and then File > Load script and select GBA-PK_Multiplayer.lua
- Click run script and close the tab. You should now have the option "MULTI" in your start menu
- Selecting MULTI will give you to option to host or connect
- Hosting will open a port on your device and give you a port number. To connect to a host, input the host ip and port number in-game

## Additional Info

GBA-PK-multiplayer features:

Coop

- Trainers beaten by one player count as beaten for the partner; money and 50 % exp paid once. Offline wins are caught up on reconnect (up to 25 trainers).
A trainer being fought is inactive for the partner; gym progress is gated by the partner.
- Shared world: cut trees, Rock Smash, Strength boulders, Snorlax, Silph Co. doors, gym switches, Rocket hideout, Mansion switches, fly points, secret bases.
- Fly map shows the partner's icon, name and location.
- Not shared: items, gifts, TMs / HMs, tutors, trades, badges.

Versus

- Walk into a trainer to make your partner battle that trainer's team in a link battle.

Soul Link

- Linked Pokemon faint together, including mid-battle; revives share the same fraction of max HP.
- Automatic linking of the n-th catch per location (starters link themselves); manual linking via console.
- Settings toggle, synced between partners; faints / revives while offline arrive on reconnect.
- Overlay panel on mGBA 0.11+ shows the linked Pokemon in party, summary and battle.
